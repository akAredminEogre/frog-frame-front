# PRレビュー対応ガイドライン

PRレビューで指摘を受けた場合の対応方針。

## スコープ内の問題

PRの変更範囲内で発生した問題は、そのPR内で修正する。

## スコープ外の問題

PRレビューで発覚したが、PRの本来の目的・範囲外の問題については、以下の手順で対応する：

### 対応手順

1. **新規ユーザーストーリーを作成**
   - `docs/user-stories/user-story-NNN/README.md` を作成
   - 問題の概要と対応タスクを記載

2. **PRコメントで説明**
   - 「本PRの範囲外のため、user-story-NNN として別途対応予定」と返信

3. **PRをマージ**
   - スコープ外の問題は別途対応するため、PRは本来の目的が達成されていればマージ可能

### 判断基準

| 状況 | 対応 |
|------|------|
| PRで編集したファイルの規約違反（今回の変更に起因） | PR内で修正 |
| PRで編集したファイルの規約違反（既存の問題） | PR内で修正 |
| PRで編集していないファイルの問題 | 新規ユーザーストーリー |
| 新規機能・大幅な設計変更が必要 | 新規ユーザーストーリー |
| テスト戦略ドキュメントの不足（既存テスト） | 新規ユーザーストーリー |

### 例

```markdown
## PRレビューコメントへの返信例

> テスト戦略ドキュメントが必須です。

本PRの範囲外のため、user-story-009 として別途対応予定です。
```
