workflow-get-new-branch-number
```cline-instructions
issue番号の採番ロジック：

1. ブランチ情報を最新化
   - `git fetch --prune origin` でリモートブランチ情報を取得

2. 最大issue番号を取得
   - ローカル、origin、claudeの全ブランチから`issue-`で始まるブランチを検索
   - ブランチ名から`issue-`の後の数字部分を抽出
   - 数値でソートし、最大の番号を取得

3. 新規番号を決定
   - 最大番号に+1して3桁にフォーマット
   - 最大番号が見つからなければ001から開始

4. 重複チェックと確定
   - 候補番号で`issue-{番号}`で始まるブランチが存在しないことを確認
   - ローカル、origin、claudeブランチすべてを対象に確認
   - 既存ブランチがあれば番号を+1して再度チェック（空になるまで繰り返す）

5. 確定した番号を3桁の文字列として出力
   - 変数 `nnn` に格納して後続処理で使用
```
