# Import Path Rules

→ ルール詳細は [`.clinerules/01-coding-standards.md`](.clinerules/01-coding-standards.md) を参照（`src` 始まりの絶対パス使用）

## tsconfig.json パス設定

Path aliases configured in `host-frontend-root/frontend-src-root/tsconfig.json`:
- `src/*` → `./src/*`
- `tests/*` → `./tests/*`
- `entrypoints/*` → `./src/entrypoints/*`
