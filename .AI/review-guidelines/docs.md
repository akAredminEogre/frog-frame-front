# docs/ ディレクトリ レビューガイドライン

docsディレクトリ内のドキュメント変更時は以下を確認してください：

## 確認項目

- docs-rules/に定義されたフォーマットに従っているか
- 関連する他のドキュメントとの整合性があるか
- テスト戦略書の場合、対応するテストファイルとの整合性を確認

## ユーザーストーリー関連

### 新規ユーザーストーリーの作成

PRレビューで発覚した問題がPRの範囲外の場合、新規ユーザーストーリーを作成して別途対応することが許容されます。

詳細: [.clinerules/02-workflow-automation/04-pull-request/04-pr-review-response.md](../../.clinerules/02-workflow-automation/04-pull-request/04-pr-review-response.md)

### 完了時の更新

ユーザーストーリー完了時は、概要セクションを過去形に更新し、タスクチェックリストを完了状態にすること。

詳細: [docs-rules/user-stories/readme-guide.md](../../docs-rules/user-stories/readme-guide.md) の「完了時の更新」セクション
