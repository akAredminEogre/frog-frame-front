# 関連ルール間の関係性を明示する

同一セクション内に複数の関連ルールがある場合、**それらの関係性（使い分け・適用範囲の違い）を明示**すること。

## 具体例

```markdown
## 悪い例（関係性が不明確）

### ADR・設計書でのルール
- 実装の詳細はソースコードを参照すること

### コーディング規約でのコード例ルール
- 著者が記載時に存在を確認すること

## 良い例（関係性が明確）

### ADR・設計書でのルール
- 実装の詳細はソースコードを参照すること

### コーディング規約でのコード例ルール
- 著者が記載時に存在を確認すること

#### 使い分け
| 用途 | 方法 |
|-----|------|
| パターン説明 | コード例を記載 |
| 完全な実装 | ソースコードへのリンク |
```

## なぜ必要か

- 読者がどのルールをいつ適用すべきか判断しやすくなる
- ルール間の矛盾や曖昧さを防ぐ
