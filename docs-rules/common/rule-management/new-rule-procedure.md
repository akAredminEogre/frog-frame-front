# 新規ルール追加時の原則

新しいルールをこのディレクトリ内（または他のdocs-rules配下）に追加する際は、以下の手順を踏むこと。

## 手順

1. 新規ルールをドキュメントに追記
2. `grep` や `Glob` で既存の違反箇所を検索
3. 以下のいずれかを選択:
   - **推奨**: 検索結果をすべて修正し、同一PRで提出
   - **代替**: 修正できない場合は「適用待ちの箇所」として記録

**例外**: `docs/completed/` 配下の履歴ドキュメントは修正対象外

詳細は [coding-standards.md](../../coding-standards.md) の「新規規約追加時のルール」を参照。
