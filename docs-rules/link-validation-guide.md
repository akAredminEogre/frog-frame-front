# ドキュメントリンク検証ガイドライン

## 目的

ドキュメント内の相対パスリンクの正確性を保ち、デッドリンク（リンク切れ）を防ぐためのガイドラインです。

## 適用範囲

- `docs/`配下のすべてのMarkdownファイル
- `docs-rules/`配下のすべてのMarkdownファイル  
- その他ドキュメントファイル内でのリンク参照

## 基本原則

### 1. リンク作成前の事前検証

ドキュメントに相対パスリンクを記載する前に、必ず参照先ファイルの存在を確認する。

### 2. 既存ファイルへのリンクのみ

存在しないファイルへのリンクは作成しない。将来作成予定のファイルへのリンクも禁止。

### 3. 相対パス計算の正確性

ディレクトリ階層を正確に計算し、適切な相対パスを使用する。

## リンク検証手順

### 作成時の必須チェック

```bash
# 1. 現在位置の確認
pwd

# 2. 相対パスの動作確認
ls path/to/target-file.md

# 3. 実際のリンクテスト
# IDE/エディタでCtrl+クリックして正しくファイルが開くか確認
```

### 段階的パス検証

```bash
# 例: docs-rules/linting-scope-consistency.mdから../../README.mdへのリンク
# 1. 一段階ずつ確認
ls ..              # 上位ディレクトリ確認
ls ../..           # さらに上位ディレクトリ確認  
ls ../../README.md # 最終ターゲットファイル確認
```

## よくある問題パターンとその対策

### パターン1: 階層計算の間違い

**問題**: `../file.md` のようにディレクトリ階層の計算を間違える

**対策**: 
- 現在位置からターゲットまでの階層を段階的に確認
- `pwd` コマンドで現在位置を正確に把握

### パターン2: 存在しないファイルへの参照

**問題**: 将来作成予定や削除されたファイルへのリンクを記載する

**対策**:
- リンク記載前に `ls` コマンドでファイル存在を確認
- 存在しない場合はリンクを削除するか、実在する代替ファイルに変更

### パターン3: ディレクトリ構造変更への未対応

**問題**: ファイル移動やディレクトリ名変更に伴いリンク切れが発生

**対策**:
- ディレクトリ構造を変更する場合は影響するリンクを全て洗い出し
- `grep -r "old-path" docs/` でリンク箇所を検索して一括更新

## 修正方針

### デッドリンクが発見された場合

1. **削除**: そのリンクが不要な場合
2. **代替リンク**: 類似の既存ファイルがある場合
3. **テキスト化**: ファイル名やパスをコード形式で記載（リンクにしない）

### 例: 修正前後

```markdown
# 修正前（デッドリンク）
- [ESLint設定ガイド](../coding-standards/eslint-configuration.md)
- [CI/CD設定ドキュメント](../development/ci-cd-setup.md)

# 修正後（実在するファイル・パスに変更）
- `eslint.config.js` - ESLint設定ファイル
- `make/test/main.mk` - CI/CDで使用するlint実行設定
```

## 自動チェック手順

### markdownlint実行時の確認

```bash
# markdownlintと併せてリンクチェックを実行
make lintmd

# 手動でのリンクチェック（利用可能な場合）
npx markdown-link-check "docs/**/*.md" "docs-rules/**/*.md"
```

### プルリクエスト作成前チェックリスト

- [ ] 新規追加したリンクは全て実在するファイルへの参照か
- [ ] 相対パスの階層計算は正確か  
- [ ] IDE/エディタでリンクが正常に機能するか
- [ ] リンク先のファイル名・パスに誤字はないか

## 予防策

### 1. リンク作成の標準化

よく使用される参照パターンを標準化し、誤りを減らす：

```markdown
<!-- よく使用されるリンクパターン例 -->
- [プロジェクト概要](../README.md)
- [CLAUDE.md](../CLAUDE.md)
```

### 2. 定期的な全体チェック

```bash
# 全ドキュメントのリンクチェック（定期実行推奨）
find docs docs-rules -name "*.md" -exec grep -l "\[.*\](" {} \; | \
  xargs -I {} echo "Check links in: {}"
```

### 3. エディタ設定の活用

- VS Code等でMarkdownプレビュー機能を使ってリンクの動作確認
- 拡張機能によるリンクチェック機能の利用
