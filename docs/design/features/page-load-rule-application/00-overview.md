# ページロード時ルール適用機能 設計概要

## 機能概要

ブラウザでページがロードされたとき、保存されているリライトルールを自動的にDOM要素に適用する機能。
ページロード後に遅延読み込みされるコンテンツ（Lazy Load）にも対応する。

## ユーザーストーリー

> ユーザーがWebページを開くと、設定したリライトルールが自動的に適用され、DOM要素が変換される

## トリガー

| アクター | イベント | トリガー |
|---------|---------|---------|
| システム | ページロード完了 | chrome.tabs.onUpdated |
| システム | DOM変更検知 | MutationObserver |

※ ユーザー操作による直接トリガーはなし

## 機能要件

### ページロード時の自動ルール適用

- ページロード完了時にリライトルールを自動適用する
- 制限されたURL（ブラウザ内部ページ等）にはルール適用しない
- 現在のURLに一致するルールのみを適用する

### 遅延読み込みコンテンツ対応

- ページロード後のDOM変更を継続監視する
- 新たに追加された要素にルールを適用する
- 連続したDOM変更はバッチ処理する

### 重複適用の防止

- ルール適用中はDOM変更監視を一時停止する
- 初回ロード完了前のDOM変更処理をスキップする
