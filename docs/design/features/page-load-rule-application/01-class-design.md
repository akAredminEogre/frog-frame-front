## クラス一覧

### enterprise-business-rules (第1層)

| クラス | 責務 |
|--------|------|
| RewriteRules | ルールコレクション。URLマッチングとDOM適用を担当 |
| RewriteRule | ルールエンティティ。URLパターンマッチ判定を担当 |
| TabUrl | タブURL値オブジェクト。URL検証ロジックを保持 |
| Elements | 要素コレクション値オブジェクト。蓄積・抽出ロジック |
| MutationRecords | MutationRecordコレクション値オブジェクト。追加要素抽出 |
| IDomRootChecker | DOM接続チェックのポートインターフェース |
| IElementFactory | 要素生成のポートインターフェース |

### application-business-rules (第2層)

| クラス | 責務 |
|--------|------|
| ApplyRulesOnDomMutationUseCase | ルール適用UseCase。初回ロードとMutation処理を担当 |
| IRewriteRuleRepository | ルール取得のポートインターフェース |
| ICurrentUrlService | 現在のURL取得のポートインターフェース |
| IDebounceTimer | デバウンス処理のポートインターフェース |
| IObserverControl | MutationObserver制御のポートインターフェース |

### interface-adapters (第3層)

該当クラスなし（システムイベントトリガーのため Controller/Presenter パターンを使用しない）

### frameworks-and-drivers (第4層)

| クラス | 責務 |
|--------|------|
| tabsOnUpdated | タブ更新イベントハンドラ。ページロード完了を検知 |
| ChromeCurrentTabService | 指定タブのタブ情報を取得 |
| ChromeTabsService | タブ操作サービス。Content Script へメッセージ送信 |
| applyAllRulesHandler | ルール適用メッセージハンドラ。Observer制御とUseCase呼び出し |
| observerOnMutate | MutationObserver登録。DOM変更を監視 |
| ObserverControl | IObserverControl の実装。Observer状態管理 |
| WindowCurrentUrlService | ICurrentUrlService の実装。現在のURLを取得 |
| WindowDebounceTimer | IDebounceTimer の実装。デバウンス処理 |
| DomRootChecker | IDomRootChecker の実装。DOM接続チェック |
| BrowserElementFactory | IElementFactory の実装。DOM要素生成 |
| ChromeRuntimeRewriteRuleRepository | IRewriteRuleRepository の実装。Messaging経由でルール取得 |
