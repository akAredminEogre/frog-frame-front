# E2Eテスト 配列ベーステスト補足ガイドライン

基本ルールは [配列ベースのテスト](../array-based-test.md) に準拠する。本ドキュメントではE2Eテスト固有の補足事項のみを定める。

## 1ファイル1配列の原則

1つのspecファイルに含められる配列化テストは**1つまで**とする。

### 理由

- E2Eテストはセットアップが重く、複数の配列化テストが混在するとファイルの責務が曖昧になる
- 観点ごとにファイルを分割することで、テストの意図が明確になる

### 適用シナリオ

- フォーカストラップの順方向・逆方向テストは1つの配列として `focus-trap.spec.ts` に配置する
- フォーカストラップとダイアログ閉じ操作のように観点が異なる配列化テストは、別ファイルに分割する

## eslint-rule

ESLint化不可（テスト構造のパターンはコード静的解析では判定困難。PRレビューで確認）
