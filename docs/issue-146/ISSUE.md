# 概要
<!-- このチケットで解決したい課題 -->
リライトルールの有効/無効を個別に切り替える機能を実装する。現在、すべてのリライトルールが常に有効になっているが、ユーザーが必要に応じて特定のルールを一時的に無効化できるようにする必要がある。

## 関連リンク
- Branch: issue-146-feat-toggle-rule-activation

# 受け入れ条件
<!-- チケットをクローズできる条件を状態として表現する -->
- [ ] 各リライトルールに対して有効/無効を切り替えるトグルボタンが表示される
- [ ] トグルの状態がストレージに永続化される
- [ ] 無効化されたルールはコンテンツスクリプトで実行されない
- [ ] トグル状態の変更が即座に反映される
- [ ] UI上でルールの有効/無効状態が視覚的に分かりやすく表示される

# 心配事
<!-- チケットを進めるうえでハードルとなりそうな懸念点を列挙します -->
- トグル状態の管理方法とパフォーマンスへの影響
- 既存のルール実行ロジックへの変更範囲
- ストレージ容量への影響
- 同期的な状態更新の実装複雑性

# 制限事項
<!-- チケットを進めるうえでの制限事項を列挙します -->
- 既存のClean Architecture構造を維持する必要がある
- Chrome拡張機能のストレージ制限内に収める
- パフォーマンスを劣化させない
- 既存のルール設定UIとの整合性を保つ
