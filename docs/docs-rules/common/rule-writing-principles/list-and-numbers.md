# リストと数値の整合性

リストを列挙する際に項目数を明示する場合、以下のルールに従うこと。

## ルール

- テーブルの行数やリスト項目数を数えて記載する場合、追記・削除時に数値も更新すること
- PR説明文で数値を使う場合、本文の項目数と一致させること

## 推奨

変動しやすいリストでは項目数を明示しない。

```markdown
## 悪い例（数値の不整合リスク）

### 対象ファイル（3ファイル）
- file1.md
- file2.md
- file3.md
- file4.md  ← 追加時に見出しの数値を更新し忘れる

## 良い例（数値を明示しない）

### 対象ファイル
- file1.md
- file2.md
- file3.md
- file4.md
```

## 例外

数値が重要な意味を持つ場合（例: 「9つのルール」のような固有名詞）は明示してよい。
