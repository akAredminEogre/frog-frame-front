# コーディング規約ドキュメントの記述ルール

## 概要

`docs/coding-standards/` 配下に配置するコーディング規約ドキュメントの記述ルール。

## 記述ルール

### 実装例は記述しない

コーディング規約には**実装例を記述しない**。

**理由**:
- 実装例はコードベース内の実際のコードを参照すべき
- ドキュメントとコードの二重管理を避ける
- 規約の本質（何をすべきか/すべきでないか）に集中する

### 記述すべき内容

- 命名規則
- 型の使い分け方針
- 禁止事項と許可事項

### 記述すべきでない内容

- 実装例（Good/Bad 例も含む）
- コードスニペット
- ユースケース固有の実装パターン

該当なし（ドキュメント記述ルールのため、PRレビューで確認）
