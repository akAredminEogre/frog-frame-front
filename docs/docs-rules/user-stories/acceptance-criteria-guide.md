# acceptance-criteria.md ガイドライン

user-story ディレクトリ内の acceptance-criteria.md 作成ルール。

## 基本ルール

ユーザーストーリーを満たすかどうかを検証する条件を記載:

- 各条件はチェックリスト形式（`- [ ]`）で記載
- AC番号は連番（AC-1, AC-2, ...）
- 基本カテゴリ（ユーザーストーリー要件、技術要件）に分類する
- 必要に応じてアクセシビリティ要件カテゴリを追加する
- 作成後、AC間で用語・表現の整合性が取れていることを確認すること
  - 例: 同じ通知方法を指す場合は「トースト通知」など統一した表現を使用

## カテゴリ

| カテゴリ | 説明 | 記述スタイル |
|---------|------|-------------|
| ユーザーストーリー要件 | ユーザー視点での機能要件 | ドメイン用語で記述 |
| 技術要件 | 実装上必要な技術的条件 | 観察可能な振る舞いで記述 |
| アクセシビリティ要件 | アクセシビリティ関連の条件（該当する場合） | ADR参照と具体的な振る舞いで記述 |

## アクセシビリティ要件（ADR-007準拠）

ダイアログコンポーネント（ConfirmDialog等）を含むユーザーストーリーでは、ADR-007で定めたアクセシビリティ要件を受け入れ条件に含めること。

### 必須項目

ダイアログを使用する場合、以下のACを追加する：

| 項目 | 受け入れ条件の例 |
|------|-----------------|
| ARIA属性 | 確認ダイアログにARIA属性が設定されている（role="dialog", aria-modal, aria-labelledby） |
| 初期フォーカス | ダイアログ表示時に最初のフォーカス可能要素にフォーカスが移動する |
| フォーカストラップ | ダイアログ内でTab/Shift+Tabによるフォーカスがトラップされる |
| 復帰フォーカス | ダイアログを閉じたときにトリガー要素にフォーカスが戻る |
| ESCキー | Escapeキーでダイアログが閉じる |
| 外側クリック | ダイアログ外側（オーバーレイ）クリックでダイアログが閉じる |
| ポータル | ダイアログはReact Portalでレンダリングされる |
| スクロールロック | ダイアログ表示中は背景スクロールが無効化される |

### 記述例

```markdown
## アクセシビリティ要件（ADR-007準拠）

確認ダイアログはADR-007で定めたアクセシビリティ要件を満たすこと。

- [ ] AC-14: 確認ダイアログにARIA属性が設定されている（role="dialog", aria-modal, aria-labelledby）
- [ ] AC-15: ダイアログ表示時に最初のフォーカス可能要素にフォーカスが移動する
...
```

## 記述上の注意

- **観察可能な振る舞いを記述する**: 具体的な変数名、クラス名、内部実装メカニズムは記載しない
  - 例: ✕「`deletingIds` による重複削除防止」→ ○「削除処理中は同じルールの削除ボタンが無効化される」
- 技術要件でも「どう実装するか」ではなく「何が検証できるか」を記述する

## README.md との違い

| 要件 | README.md（開発タスク） | acceptance-criteria.md（受け入れ条件） |
|------|------------------------|---------------------------------------|
| 重複削除防止 | `deletingIds` による重複削除防止 | 削除処理中は同じルールの削除ボタンが無効化される |
| 非同期処理 | messaging経由でBackground Scriptに送信 | 削除処理中もブラウザや他タブの操作がブロックされない |
| アーキテクチャ | Controllerは Factory 経由で生成（ADR-005準拠） | Clean Architectureの層構造が遵守されている（コードレビューで検証） |
| コンポーネント配置 | ConfirmDialog をRulesApp内でレンダリング | 確認ダイアログが表示される |

## テンプレート

```markdown
# 受け入れ条件

## ユーザーストーリー要件

- [ ] AC-1: トグル操作でルールの有効/無効が切り替わる
- [ ] AC-2: 変更が保存される

## 技術要件

- [ ] AC-3: 該当URLのタブがリロードされる
```
