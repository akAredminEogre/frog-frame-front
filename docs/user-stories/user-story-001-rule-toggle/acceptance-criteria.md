# 受け入れ条件

## 機能要件

### AC-1: 有効/無効トグル表示

- [ ] ルール一覧の各行にトグルスイッチが表示される
- [ ] トグルスイッチは現在の `isActive` 状態を反映している
- [ ] 有効（ON）の場合は視覚的に区別できる（色、位置など）

### AC-2: 有効/無効トグル操作

- [ ] トグルスイッチをクリックすると `isActive` が反転する
- [ ] 変更は即座にDBに永続化される
- [ ] 画面をリロードしても状態が保持されている

### AC-3: タブリロード

- [ ] ルールを無効化した場合、該当URLのタブがリロードされる
- [ ] ルールを有効化した場合、該当URLのタブがリロードされる

### AC-4: 置換前/後プレビュー

- [ ] 各ルールで「置換前」「置換後」を切り替え表示できる
- [ ] デフォルトは「置換前」表示
- [ ] タブ形式のUIで直感的に切り替え可能

## 非機能要件

### AC-5: パフォーマンス

- [ ] トグル操作から200ms以内にUIが更新される
- [ ] DB永続化の失敗時はエラーメッセージが表示される

### AC-6: アクセシビリティ

- [ ] トグルスイッチに `role="switch"` が設定されている
- [ ] トグルスイッチに `aria-checked` が設定されている
- [ ] キーボード操作（Enter/Space）でトグル可能

### AC-7: レスポンシブ

- [ ] 狭い画面幅でもトグルスイッチが操作可能

## 技術要件

### AC-8: アーキテクチャ

- [ ] Clean Architecture 4層構造に準拠
- [ ] フルnrslibパターン（Controller/Interactor/Presenter）を使用
- [ ] 依存性逆転の原則に従っている

### AC-9: テスト

- [ ] Interactorの単体テストが存在する
- [ ] Controllerの単体テストが存在する
- [ ] UIコンポーネントのStorybookが存在する
- [ ] E2Eテストでトグル操作が検証されている

### AC-10: コード品質

- [ ] `make testlint` がパスする
- [ ] 未使用コードがない
- [ ] TypeScriptの型エラーがない
