# 受け入れ条件

ユーザーストーリー「ルール一覧でルールの有効/無効を切り替えられる」を満たすための条件。

## ユーザーストーリー要件

- [x] AC-1: ルール一覧の各行にトグルスイッチが表示される
- [x] AC-2: トグルスイッチは現在の有効/無効状態を反映している
- [x] AC-3: トグル操作でルールの有効/無効が切り替わる
- [x] AC-4: 変更がDBに保存される
- [x] AC-5: 画面をリロードしても状態が保持されている

## 技術要件

- [x] AC-6: ルールの有効/無効を変更した場合、該当URLのタブがリロードされる
  - RewriteRule.matchesUrl() でURLマッチング判定（ADR-001参照）
- [x] AC-7: DBアクセスはmessaging経由でBackground Scriptに集約される（ADR-003参照）
- [x] AC-8: Entity ↔ DTO変換はRewriteRuleMapperが担当する（ADR-002参照）

## エラーハンドリング要件

- [x] AC-9: ルール取得失敗時、UIの状態は変更されずエラーメッセージが表示される
- [x] AC-10: ルール更新失敗時、UIの状態は変更されずエラーメッセージが表示される
- [x] AC-11: タブリロード失敗時（部分的成功）、UIはトグル後の状態を表示しエラーメッセージも表示される
- [x] AC-12: トグル処理中は同一ルールに対する連続トグル操作が防止される（競合状態防止）
- [x] AC-13: エラー情報はToggleRuleActiveErrorOutputDataで伝達される
