# 受け入れ条件

## ユーザーストーリー要件

- [x] AC-1: ルール一覧の各行にゴミ箱アイコンが表示される
- [x] AC-2: ゴミ箱アイコンをクリックすると確認ダイアログが表示される
- [x] AC-3: 確認ダイアログで「削除」を選択するとルールが削除される
- [x] AC-4: 確認ダイアログで「キャンセル」を選択すると何も起こらない
- [x] AC-5: 削除されたルールがルール一覧から消える
- [x] AC-6: 削除失敗時はトースト通知でエラーメッセージが表示される

## 技術要件

- [x] AC-7: 削除されたルールのURLパターンに一致するタブがリロードされる
- [x] AC-8: 削除処理中は同じルールの削除ボタンが無効化される
- [x] AC-9: 部分的成功時（削除成功・タブリロード失敗）はルールを一覧から削除し、トースト通知でエラーメッセージを表示
- [x] AC-10: ルールはDBから物理削除される（論理削除ではない）
- [x] AC-11: 削除処理中もブラウザや他タブの操作がブロックされない（非同期処理）
- [x] AC-12: 作成・変更したクラスの依存関係が外側の層から内側の層への単方向であり、内側の層が外側の層に依存していないことがeslint-ruleにより保証されている
- [x] AC-13: make testcheck がパスする

## アクセシビリティ要件（ADR-007準拠）

確認ダイアログはADR-007で定めたアクセシビリティ要件を満たすこと。

- [x] AC-14: 確認ダイアログにARIA属性が設定されている（role="dialog", aria-modal, aria-labelledby）
- [x] AC-15: ダイアログ表示時に最初のフォーカス可能要素にフォーカスが移動する
- [x] AC-16: ダイアログ内でTab/Shift+Tabによるフォーカスがトラップされる
- [x] AC-17: ダイアログを閉じたときにトリガー要素（ゴミ箱アイコン）にフォーカスが戻る
- [x] AC-18: Escapeキーでダイアログが閉じる
- [x] AC-19: ダイアログ外側（オーバーレイ）クリックでダイアログが閉じる
- [x] AC-20: ダイアログはReact Portalでレンダリングされる（z-index問題回避）
- [x] AC-21: ダイアログ表示中は背景スクロールが無効化される
