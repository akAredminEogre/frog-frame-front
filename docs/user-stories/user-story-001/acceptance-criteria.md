# 受け入れ条件

ユーザーストーリー「ルール一覧でルールの有効/無効を切り替えられる」を満たすための条件。

## ユーザーストーリー要件

- [ ] AC-1: ルール一覧の各行にトグルスイッチが表示される
- [ ] AC-2: トグルスイッチは現在の有効/無効状態を反映している
- [ ] AC-3: トグル操作でルールの有効/無効が切り替わる
- [ ] AC-4: 変更がDBに保存される
- [ ] AC-5: 画面をリロードしても状態が保持されている

## 技術要件

- [ ] AC-6: ルールの有効/無効を変更した場合、該当URLのタブがリロードされる
  - RewriteRule.matchesUrl() でURLマッチング判定（ADR-001参照）
- [ ] AC-7: DBアクセスはmessaging経由でBackground Scriptに集約される（ADR-003参照）
- [ ] AC-8: Entity ↔ DTO変換はRewriteRuleMapperが担当する（ADR-002参照）
